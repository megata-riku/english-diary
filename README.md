# 自分の言葉で学ぶ英語日記

日本語で書いた日記を、英訳・読み上げ・表現集に変える個人用の英語学習Webアプリです。自分が実際に話したい出来事から、使いたい英語を蓄積することを目指しています。

iPhoneのキーボード音声入力で日本語を入力し、PC上のアプリで保存・英訳できます。音声認識モデルや録音機能を独自実装したものではありません。

## 画面例

### 日記から英語を学ぶ

日本語の日記を英訳し、全文や選択した部分を読み上げます。

![日記と英訳・読み上げ機能](docs/diary.png)

### 覚えたい表現を蓄積する

選んだ表現の意味・ニュアンス・文脈を自動取得し、自分用のメモと一緒に保存します。

![保存した表現と意味・ニュアンス・メモ](docs/expressions.png)

## 開発のきっかけ

"日記は続かず、語学は難しい"

両者を無理なく続けられる仕組みを作りたいと考えたことが、開発の出発点です。
語学力の向上を日記を書く動機にし、自分の言葉を学習素材にすることで語学への関心を保つ。それぞれが互いに続ける動機になることを目指し、自分の言葉から教材を作るアプリを開発しました。

## できること

| 機能 | 内容 |
| --- | --- |
| 日記 | 日本語の保存・一覧表示・確認付き完全削除 |
| 英訳 | OpenAI APIによる英訳と保存。取得済みの英訳は再利用 |
| 読み上げ | ブラウザの音声合成による全文・選択範囲の再生、停止、速度調整 |
| 表現集 | 英訳から選んだ表現を保存。同じ日記内の同一表現は重複防止 |
| 意味の自動取得 | 表現保存後、元の英文を使って意味・短いニュアンス説明・文脈を取得 |
| 再試行 | 説明取得に失敗しても表現を保持し、一覧から再試行 |
| メモ | 表現ごとに最大5,000文字のメモを保存・更新・空にする |
| データの保持 | 日記を削除しても保存した表現・取得済みの説明・文脈・メモは保持 |

## 利用の流れ

1. 日本語を入力する。iPhoneではキーボードの音声入力も利用できる。
2. 入力内容を確認・修正し、「日記を保存」を押す。
3. 「英訳する」を押し、英文を読む・聴く。
4. 覚えたい英文を選択して「選択した表現を保存」を押す。
5. 自動取得された意味・ニュアンス・短い文脈を確認する。
6. 必要なメモを書いて保存し、後から一覧で見返す。

## 設計上の工夫

### 保存とAI処理を分離

日本語の日記を保存してから英訳を要求し、表現も保存してから別のAPIで説明を取得します。AI処理に失敗しても、入力済みの日記や選択した表現を失わずに再試行できます。

### 保存済みの結果を再利用

英訳・説明の取得済み判定をサーバー側でも行い、通常の再取得では外部APIを呼びません。

### 日記と学習表現の寿命を分離

日記を削除しても、学習用の表現は残す仕様にしました。日記と英訳の削除、表現の日記IDの解除を一つのトランザクションにまとめています。表現の削除は独立して行います。

### AI出力を検査し、引用不一致から復旧

説明のJSON形式、必須文字列、意味・ニュアンスの長さを確認します。文脈が元の英文の抜粋になっていない、または選択表現を含まない場合には、選択した英文そのものを文脈として保存します。

### 操作とエラーの区別

保存成功後の一覧更新失敗と、保存自体の失敗を分けて表示します。削除は確認ダイアログを経て行い、サーバーの成功応答後に画面から除きます。SQLには値のプレースホルダーを使い、本文は画面でtextContentに設定します。

## ローカル起動（Windows / PowerShell）

添付・ダウンロード時にファイル名に番号が付く場合は、main.py、static/app.js、static/index.htmlとして配置してください。staticフォルダは起動前に必要です。

以下は必要なライブラリから組み立てたセットアップ手順です。依存バージョンの固定と、新規環境での再現確認は未実施です。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

main.pyと同じ場所に.envを作成します。

```dotenv
OPENAI_API_KEY=ここに自分のAPIキーを設定
```

起動：

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

PCで http://127.0.0.1:8000 を開きます。API一覧は http://127.0.0.1:8000/docs で確認できます。初回起動時にDBが作成されます。既存DBを更新する前には、サーバーを停止してバックアップしてください。

家庭内Wi-FiでiPhoneから使う場合：

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 0.0.0.0
```

PCとiPhoneを同じ信頼できる家庭内ネットワークに接続し、iPhoneから http://PCのIPv4アドレス:8000 を開きます。Windowsではプライベートネットワーク向けに必要なPythonの通信を許可します。利用中はPCとサーバーの起動が必要です。

## 現在の制約・公開時の扱い

- 個人のローカル・家庭内利用向けです。ログインやユーザーごとのデータ分離はありません。現在の構成をそのままインターネットに公開する用途には対応していません。
- 英訳時には日本語の日記、意味取得時には選択表現と元の英訳をOpenAI APIへ送信します。コードではstore=Falseを指定しています。API利用料金は利用者負担です。
- 音声入力の処理は端末側の機能に依存します。読み上げは選ばれた音声により外部サービスを利用する場合があり、画面に表示します。
- 日記削除後も、取得済みの短い文脈などは表現集に残ります。説明取得前に元の日記を削除し、文脈が未保存の場合は説明を取得できません。
- 意味・ニュアンス・文脈・日記本文の手動編集は未実装です。編集できるのは自分用メモです。
- メモは手動保存です。一覧の更新や再読み込みで未保存の入力が失われる場合があります。
- 全文選択や長文では出力上限・JSON形式により説明取得が失敗する可能性があります。再試行と入力保持に対応しています。
- .env、diary.db、DBのバックアップ、個人の日記が映る画像は公開用コードに含めません。

### 60秒程度のデモ構成

| 時間の目安 | 操作・画面 | 伝える内容 |
| --- | --- | --- |
| 0〜8秒 | 日本語の日記を入力・保存 | 自分の出来事を教材にする |
| 8〜20秒 | 英訳する | 日本語を先に保存してから翻訳する |
| 20〜28秒 | 英文の一部を再生・停止 | 音でも確認できる |
| 28〜43秒 | 表現を選んで保存 | 意味・ニュアンス・文脈を自動取得する |
| 43〜53秒 | メモを入力・保存 | 自分の学習メモを残せる |
| 53〜60秒 | 再読み込みして表現を表示 | 保存した教材を後で見返せる |

APIの待ち時間は録画後に短縮しても構いませんが、その区間に「待ち時間を短縮」と明示し、実測の速度として提示しないでください。録画はアプリ画面を中心にし、APIキー、個人の日記、通知を映さないようにします。
